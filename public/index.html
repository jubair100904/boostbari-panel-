সহায়তা

অর্ডারের আগে সার্ভিসের বিবরণ, ডেলিভারি সময়, রিফিল/রিফান্ড নীতি নিশ্চিত করুন।

এই ডেমোতে তথ্য শুধু এই পেজে দেখানো হয়; সার্ভারে পাঠানো হয় না।

নতুন অর্ডার

এই স্টার্টার প্রজেক্টে অর্ডার API অ্যাডমিন পাসওয়ার্ড দিয়ে সুরক্ষিত। কাস্টমারদের জন্য পাবলিক অর্ডার চালু করার আগে লগইন, পেমেন্ট যাচাই, rate limit ও অপব্যবহার প্রতিরোধ যোগ করুন। কখনো Provider API key দেবেন না।

API যুক্ত করার আগে

  • Provider-এর অফিসিয়াল API ও মূল্য যাচাই করুন।
  • API key শুধু সার্ভার-side-এ রাখুন, HTML/JavaScript-এ নয়।
  • SSL certificate যাচাই বন্ধ করবেন না।
  • পেমেন্ট, অর্ডার লগ, রিফান্ড ও abuse protection যোগ করুন।

এই ডেমোতে API key রাখা হয়নি এবং GetmyFollow-এ কোনো live request পাঠানো হয় না।
